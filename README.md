## How it works

`main.py` is Python 3.13 standard library only, with no network access.
It writes exactly one byte, the letter `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), and asserts before writing that the entry is
a single letter from `A` or `B`, so an invalid entry can never be produced.

## Why A

The judge weighs which letter feels more vivid, funnier, or truer.
Coffee is the bolder answer: the drink that wakes you up, the one with
the stronger smell, the darker cup, the louder morning. A single `A`
carries that whole stance — no explanation needed beside it.
